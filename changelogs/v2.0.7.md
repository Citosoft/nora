### Features

- Show Claude's running background tasks (shells, monitors, agents) on the thread until they finish, even after the turn that started them ends.
- Add per-workspace setup scripts that run automatically when a worktree is created or before it is removed, or on demand from the Run script menu, edited under Presets & setup scripts.
- Customise every keyboard shortcut in Settings → Keybindings: record a new chord, unbind or reset commands, and see clashing shortcuts; the app menu and shortcut help follow your choices.
- Import from Claude, Codex, T3 Code and Orca in one checklist, during onboarding or in Settings → Migrate: projects from all four (a folder several apps know shows once), plus threads (resumable where the Claude/Codex session still exists, otherwise read-only history), setup scripts, presets, default model, appearance, shortcuts and opt-in environment variables from T3 Code and Orca, without duplicating anything on a re-run.
- Jump around with the keyboard: Cmd/Ctrl+Alt+1–4 show Inbox, Threads, Bots and Apps, and Cmd/Ctrl+Alt+T, W, G, R, U, N and L open the active workspace's Tasks, Workflows, Worktrees, Merge Requests, Issues, Documents and Library (all rebindable in Settings → Keybindings).
- Bring bots over from Orca, OpenBot and Grok Bot during onboarding or in Settings → Migrate: instructions, skills, model, avatar colours, memory and routines (which arrive paused); Grok Bot bots, and OpenBot bots kept on a server (Nora says when OpenBot is connected to one), come from an export the app's bot writes using a prompt Nora provides.
- On Macs with a notch, an island beside the camera shows who is working while threads and terminal agents run (the bot or provider of whatever waits on you, else the latest), with an inbox button on the other side: hover to list all active work and click one to open it; choose whether it shows, keep it up when idle for its inbox button, set its size (never smaller than the notch) and preview it in Settings → Notch island.
- Settings → Privacy now separates anonymous usage statistics (on by default where the law allows, off with one switch, and opt-in in the EEA and Switzerland) from opt-in detailed analytics, lists exactly what each sends, keeps analytics on PostHog's EU cloud, and Nora's assistant can no longer change these choices for you.
