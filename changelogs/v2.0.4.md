### Features

- Pick a theme from named light-and-dark orbs in Settings > Appearance: Nora (the original look), Slate, Ocean, Forest, Sand, Dusk, Rose, Ember, Olive or Jade, each with light and dark variants and its own accent color, which a fixed Accent Color can still override.
- Choice questions in threads always include an Other option so you can type a custom answer.
- Asked bots can edit files: global bots always get write access, and workspace bots inherit the caller's access.
- Show whether a thread is Writable or Read-only in the composer and thread details, and click the badge to switch when the thread is idle.
- Reset a bot's home chat from the DM sidebar: the old chat is settled and kept in the thread list, and a fresh chat with the bot opens.

### Improvements

- Bot DMs drop the bot name and avatar from the tab row, and the Chat tab is now a home icon.
- Project session tabs now sit in the title bar, lined up with the content area beneath a divider that continues the sidebar border, and project search (Ctrl/⌘+K) opens from a search icon beside the role switcher.
- Switch your work role from the title bar, where role tiles preview each role's sidebar tools as you hover; the new thread screen no longer shows the role label.
- Refreshed the workspace home in Nora's pixel style, with project tools as tiles that show and change which tools are pinned to the sidebar.
- Your work role now picks which tools start pinned in the sidebar, such as Terminal, MRs and Issues for developers or Tasks and Workflows for operations, until you pin your own.
- Threads can show an animated pixel terrain background whose cells light up under the cursor and fade as you move away, turned on in Settings > Appearance for new threads or all threads, with a slightly see-through composer on new threads.
- Load restored thread tabs when first opened and combine overlapping thread list refreshes.
- Build the Files and changed-files trees faster for directories with many siblings.
- Skip search indexing while Quick Search is closed and stop scanning each group once its results are full.
- Reduce background checkout checks when working with multiple workspaces.
- Keep streamed workflow output responsive by combining pending disk writes.
- Reduce app refresh work for large source results and multiple alerts, and reload only stale sources on return.
- Update Inbox marks, workflow notices, and connector alerts without reloading unchanged thread summaries.
- Improve terminal typing responsiveness, especially with long command lines and multiple terminal tabs.
- Reduce database work during streamed chat and tool updates.
- Load conversation summaries with fewer database calls and skip run summaries during idle thread maintenance.
- Reduce repeated work when displaying large thread lists and their pull request badges.
- Pause pull request and tool usage polling while the window is hidden and refresh on return.

### Fixes

- Development builds keep their own data in `~/.nora-dev` and a separate app data folder, so running Nora from source no longer breaks or blocks the installed app.
- Keep composer model options stable during thread updates and model refreshes by sharing checkout catalogs.
- End a jammed thread turn with End turn when Stop hangs on Stopping or the outcome stays unconfirmed after Check native status.
- Fixed custom MCP sign-in failing before opening the browser when the server advertises a separate OAuth discovery URL.
- Show MCP connection and sign-in errors directly in Settings, including actionable DNS and network failure details.
- Fixed MCP connections to servers using system-trusted private certificate authorities and explain certificate verification failures.
- Stop retrying permanently rejected MCP credentials until you sign in again, and respect Retry-After for temporary failures.
