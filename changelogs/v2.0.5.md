### Features

- Let ask_bot return immediately by default (wait=notify) and post the bot's answer into the parent thread when it finishes, with wait=reply when the answer is needed first.
- Add a UI font size setting under Appearance.
- Let agents list, open, and paste into terminals (including the local dock) for you to run.
- Let Nora list, create, update, and remove bot routines from chat.
- When a thread needs an OAuth connector that is not signed in, show an authorize card with the connector logo and pause the tool call until you authorize or decline.
- Undo a turn's file changes from its Edited files card, with conflicts listed when files changed since; the last 20 turns per thread can be undone.
- Get a push notification on your iPhone when a thread finishes or needs you, and tap it to open that thread; turn it on from the card on the phone's home screen or in its Settings, and control it with “Notify my phone” in Nora's General settings.

### Improvements

- Reduce composer input latency and avoid reparsing unchanged thread messages.
- Show connector icons on MCP calls and in the thread’s tool history.
- Show website favicons beside links in thread messages.
- Show mentioned bots as pills with their configured avatars in messages.
- Let threads and delegated bots work concurrently in a shared checkout, with workspace-level review when edits overlap.
- Cut delegated Claude/Codex context: bots, chats and write workers use an `agent` tool scope (strict MCP, no user-global skills) so side threads stop inheriting the Personal MCP catalogue.
- Cap chat handoffs for new bot tasks at a short recent slice, with older messages available via `chat_history`.
- Make Nora connectors opt-in per bot (and give plain workers none by default) so each turn no longer loads every connector tool catalogue.
- Give bot-less workers a slim Nora tool set, drop terminals/routines from bots, and shorten handoff/tool guidance copy.
- Cap continuing chat/group transcript handoffs at the same recent 4k-character slice as new tasks.
- Animate the thread background only while the thread is working; it holds still when idle.

### Fixes

- Keep the animated background at a low frame rate on hover and stop the animation with reduced motion or an unfocused window.
- Batch background drawing and cache grid geometry to reduce renderer CPU use.
- Extend the thread background's faint dots across the full width of the thread pane.
- Ship production React in the packaged renderer.
- Show delivery warnings only after an unconfirmed send.
- Follow the latest messages when you send a prompt in an existing thread.
- Hide unsupported Git review messages in threads.
- Return control to the parent thread before an ask_bot call times out, with a link to the delegated work.
- Keep execution available while other turns run, and end stalled starts and stops without restarting Nora.
- Turn off the animated thread background while hardware acceleration is disabled.
- Label worker-thread tools in the built-in Nora MCP server details instead of showing “undefined”.
- Show turn diffs for every edited file in large repositories instead of “Diff unavailable” for files that sort late in the checkout.
- Let the iPhone app read chats and settings from the latest Nora Desktop again (it rejected newer bot-chat and settings fields).
