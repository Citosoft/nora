### Features

- Run installed ACP coding agents such as Cursor, OpenCode, Google Antigravity, Grok, Copilot, Goose and Kimi as native thread providers, with their own models and modes, approvals, interrupts, sign-in status and provider icons, connecting agents installed while Nora runs without a restart.

- Show whether Claude and Codex are signed in, with the plan and account, on each provider in Providers settings, and sign in from there through each runtime's browser sign-in.

- Discover MCP servers and tools from Codex and Claude runtimes in a dedicated MCP Servers settings table showing each server's own logo and provider icon, global or workspace scope, connection status and tools, with refresh, runtime sign-in guidance and an explanation when Claude account connectors cannot load.

- Generate commit messages and new thread names using signed-in Codex or Claude runtimes, API keys, or local models.

- Show a PR icon with its number and state in the tooltip for sidebar threads linked to a branch pull or merge request, alongside activity and attention indicators.

- Add a provider usage-limit simulator scenario to preview an exhausted provider account and example reset time in the chat and sidebar.

- Steer queued messages into an active turn when the configured runtime supports it, with delivery confirmation and protection against duplicate submission.
- Add a streamed Markdown gallery to the chat simulator for testing headings, emphasis, lists, tables, quotes, links, task lists, and code blocks.
- Enable structured chat questions and present them as selectable choice cards with single- and multi-select support, keyboard controls, and complete-answer submission.
- Add an isolated developer chat simulator for exercising streaming, tools, questions, approvals, queues and recovery without LLM tokens or real tool execution.
- Add a floating thread-details panel with reviewed file and line changes, branch PR/MR status, and archive controls in place of each thread's header row.
- Replace separate managed-agent and AI-chat entry points with native threads in the existing workspace shell, while retaining manual terminals and workspace tools.
- Prepare unified thread navigation, tabs and a direct chat composer that restores independent drafts and safely retries unconfirmed instructions.
- Prepare a provider-and-model popover for v3 threads, with provider icons, native model catalogs and selection that preserves drafts and permissions.
- Prepare role-based onboarding, app defaults and workspace overrides, a no-repository Personal workspace, and guidance saved per conversation for Nora’s existing interface.
