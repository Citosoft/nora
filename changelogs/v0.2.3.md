### Features

- Settle idle threads to hide them without deleting history, then browse Settled threads and reopen them when needed.
- Discover local Codex and Claude CLI and desktop coding conversations, resume them with saved history and native context.
- Show workspaces together with colorful two-letter avatars and user-selectable colors, plus saved Workspace, Activity, or flat thread grouping in the sidebar.
- Add Claude's Auto permission mode and distinguish Manual, Accept edits, and Plan with descriptions of how approvals work.
- Show Claude's suggested follow-up as ghost text in an empty chat composer, with Tab to accept without sending and a simulator scenario for trying it.
- Add a Stacked approvals simulator scenario that raises three requests together for testing approval, denial, and stopping the task.
- Run installed ACP coding agents such as Cursor, OpenCode, Google Antigravity, Grok, Copilot, Goose and Kimi as native thread providers, with their own models and modes, approvals, interrupts, sign-in status and provider icons, connecting agents installed while Nora runs without a restart.

- Show whether Claude and Codex are signed in, with the plan and account, on each provider in Providers settings, and sign in from there through each runtime's browser sign-in.

- Discover MCP servers and tools from Codex and Claude runtimes in a dedicated MCP Servers settings table showing each server's own logo and provider icon, global or workspace scope, connection status and tools, with refresh, browser sign-in for Codex and Claude servers that need it (including claude.ai connectors) without leaving Nora, and an explanation when Claude account connectors cannot load.

- Generate commit messages and new thread names using signed-in Codex or Claude runtimes, API keys, or local models.

- Show a PR icon with its number and state in the tooltip for sidebar threads linked to a branch pull or merge request, alongside activity and attention indicators.

- Show how full the thread's context window is as a donut beside Send for Claude and Codex, including existing and resumed threads read from saved history, with token details and a Compact context button in a hover popover.
- Show compact stacked toasts in the bottom-left on launch, each with the provider's icon, for every installed provider CLI (Claude Code, Codex, and other npm-distributed agents) that is behind its latest release, with Update and Dismiss buttons; dismissed updates stay available from an icon at the bottom of the sidebar until the next launch.
- Show a Nora icon at the bottom of the sidebar while a Nora update is downloading, ready to install (click to restart and install), or available as a Linux release.
- Show the selected provider's weekly and 5-hour usage as a double donut beside the composer's model picker, with limits, reset times, plan details and refresh in a hover popover.

- Show a connector sign-in card in chat when the model asks you to sign in to an MCP connector, with sign-in, retry and live connected status shared with thread details, plus a Connector sign-in simulator scenario.
- List a thread's running and finished Claude and Codex subagents in thread details with the model and effort each ran on, each expandable to its task, live progress, result and its own tool calls, plus a Subagents simulator scenario.
- Show the skills a thread loaded or read in thread details, marked Loaded (reported by Claude) or Read (from the skill's SKILL.md), with the agent and calls that used each and the rest of the runtime's skills listed as available, plus a Skills simulator scenario.
- Choose a default subagent model for new Claude threads in the model picker, shown beside the thread's model and reasoning.
- Add a provider usage-limit simulator scenario to preview an exhausted provider account and example reset time in the chat and sidebar.

- Steer queued messages into an active turn when the configured runtime supports it, with delivery confirmation and protection against duplicate submission.
- Add a streamed Markdown gallery to the chat simulator for testing headings, emphasis, lists, tables, quotes, links, task lists, and code blocks.
- Enable structured chat questions and present them as selectable choice cards with single- and multi-select support, keyboard controls, and complete-answer submission.
- Add an isolated developer chat simulator for exercising streaming, tools, questions, approvals, queues and recovery without LLM tokens or real tool execution.
- Add a floating thread-details panel with reviewed file and line changes, branch PR/MR status, and archive controls in place of each thread's header row.
- Show the MCP connectors enabled by a thread's provider in thread details, with each connector's logo, name and tool count or status, the first few inline and the rest in a Show more popover, in a taller details panel with a visible scrollbar, and sign in to connectors that need it from their row.
- Replace separate managed-agent and AI-chat entry points with native threads in the existing workspace shell, while retaining manual terminals and workspace tools.
- Prepare unified thread navigation, tabs and a direct chat composer that restores independent drafts and safely retries unconfirmed instructions.
- Prepare a provider-and-model popover for v3 threads, with provider icons, native model catalogs and selection that preserves drafts and permissions.
- Prepare role-based onboarding, app defaults and workspace overrides, a no-repository Personal workspace, and guidance saved per conversation for Nora’s existing interface.
