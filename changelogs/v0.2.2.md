### Features

- The focused agent or terminal's top-right info bar now shows its checkout folder (full path on hover) and a branch picker that switches the branch checked out in that folder.
- Project rows in the sidebar have a + button that opens a new agent tab with your default harness in one click, in the project folder at its current checkout.
- Cursor Agent's footer usage popover now shows your monthly usage, reset date, plan, Auto/API usage split, and bonus usage, read via the Cursor desktop app's sign-in.
- The Settings sidebar now has a search box that filters settings by name and keyword; picking a result opens its section and scrolls to and highlights that setting.

### Improvements

- Sidebar thread rows now show only the title, with the full title, agent, project, and last-updated date in a hover tooltip.
- Each sidebar thread group now lists its 5 most recent threads, with a "Show more" toggle to reveal the rest.
- Collapsing the right sidebar now hides it completely instead of leaving a narrow strip with an icon and count.
- Active ports moved from the projects sidebar to an icon on the right of the footer that opens a popover listing each port, with actions to focus its terminal or open it in the app browser or externally.
- Remote mounts moved from the projects sidebar to an icon on the right of the footer that opens a popover listing each SSH mount, with actions to choose a repository in it or unmount it.
- AI chatbot shortcuts (ChatGPT, Claude, Gemini, Perplexity) moved from the projects sidebar to a footer icon that opens them in the internal browser.
- Projects without a favicon file now use the favicon of the `homepage` URL in their `package.json` as the project icon.
- The project home screen now shows the `package.json` homepage as a link that opens in the project browser.
- The sidebar projects list drops its row borders for borderless rounded rows like the Threads and Agents sections, and marks the active project with a small accent bar and bolder name instead of a full-row highlight.
- The Settings screen drops its large title header for a compact top bar with a Back button (with a back arrow) at the top left.

### Fixes

- Nora no longer runs out of memory and crashes when you have large Codex session histories; Codex threads are now identified without loading whole session files.
- Sidebar project session counts now stay aligned across projects, whether or not a project has runnable scripts.
- When the window fails to render, crashes, or hangs, Nora now shows a recovery screen or prompt with Reload and Copy error details instead of a blank window, and View → Reload is available on macOS.
- Claude Code's footer usage popover now shows your session and weekly limits (when your plan has them), plan, signed-in account, usage credits, and why usage is unavailable when it cannot be loaded.
- Threads in the sidebar now show their session title (or opening prompt) instead of the harness name and session ID.
- Codex thread titles and Cursor usage now load on Windows and Linux without needing the `sqlite3` command-line tool installed.
- The footer's enabled agents no longer shows installed agents you have disabled after opening or switching projects.
