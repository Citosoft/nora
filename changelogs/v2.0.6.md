### Features

### Improvements

- The title bar and the new thread screen now show Nora's pixel "N" on its own, in black or white to match the theme, instead of the boxed app icon.
- The "What type of work do you do?" onboarding screen now sits on the animated dot terrain from threads, filling the whole window.
- Replace the thread composer with a provider setup checklist when no coding agent is available, linking to Settings → Providers and detecting newly installed agents when you return.
- When a provider needs signing in, the model picker now offers a Sign in button that opens Settings → Providers instead of sending you to the agent's CLI.

### Fixes

- Keep Claude's background tasks (background shells, monitors and background agents) running after its turn ends, and show what Claude reports when they finish as a new turn in the thread.
- Only ask you to authorize a connector when a thread actually calls one of its tools, not for every signed-out connector the thread loads at start.
- On Windows, start Codex, Claude Code and other agent CLIs that npm installs as `.cmd` shims, so Codex models load instead of reporting that model discovery is unavailable, including when the Windows user name contains spaces.
